مشروع تطبيق الأسئلة - Android

البناء:
1) ارفع جميع محتويات هذا المجلد إلى مستودع GitHub جديد أو مستودعك الحالي.
2) افتح تبويب Actions.
3) اختر Build AlAs2ila APK ثم Run workflow.
4) بعد نجاح البناء افتح نتيجة التشغيل وحمّل Artifact باسم AlAs2ila-debug-apk.
5) فك ضغط الملف لتحصل على app-debug.apk.

التطبيق يفتح واجهة HTML محلياً داخل WebView، ولا يحتاج اتصال إنترنت أثناء الاستخدام.
هذه نسخة Debug للتجربة والتثبيت اليدوي، وليست إصدار متجر Play موقّعاً للنشر.
